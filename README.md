# tokyo-23-pools

東京23区の公共プール（区営・都営・国営・都立公園）111施設のインタラクティブマップ。

**Live map: https://ymtezo.github.io/tokyo-23-pools/**

- 出典: Zehitomo Journal「東京23区内の区民プール105施設」(実在103施設に正規化) + 都営・国営・記事未収録区営8施設を追加
- 営業時間(特に最終終了時刻)で色分け・フィルタ可能
- 座標: 公式住所を国土地理院APIで解決 / OpenStreetMap / Nominatim
- ,  は他のマップツールにインポート可能
- 営業時間は変更される可能性があります。利用前に必ず公式ページで確認してください
